# Reusable framework canvas

Run `npm run canvas:build` from the repository root, then `npm run canvas` for a loopback-only preview at port 9472. The canvas uses the same near-function Bend primitives, component kit and browser adapters. It retains pan/zoom, page/frame navigation, nested geometry/layout inspection, dark/light schemes, motion scrubbers and resize stages. Its specimens contain neutral framework examples and a generated geometric SVG. Custom sprite artwork is caller-supplied; none is bundled.

Application-specific workflows and their screen/state simulators remain in their original application repository. Open Dot remains the separate reusable assistant template. This canvas does not create users, redeem access, read receipts, or contact providers.
